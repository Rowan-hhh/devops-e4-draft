# ADR：E13 B2 以字节哈希和隔离副本保护失败测试

## 决策

1. C3 复制 B1 报告后只修改隔离副本，并把原始 SHA 作为消费时的期望值；原件不改写。
2. C5 在项目独立克隆上调用现有 validation sandbox，错误补丁在 `git apply --check` 阶段拒绝，保存验证结果和源树前后状态。
3. H2-inih 的请求由其独立 Git 仓库的最新两个提交现场读取，避免手填或混用其他项目的 commit。
4. 教师项目源码、sandbox、对象文件和可执行文件不进入公开仓库，只提交可审查证据。

## 取舍

保留逐文件 SHA 和运行日志使报告可复核，但会增加证据体积；排除源副本和 `.git` 元数据减少泄露课程材料的风险。H2 的最终 `recheck` 仍保留 `REDUNDANT` 观察，不将“无 MISSING”夸大为“无任何 finding”。
