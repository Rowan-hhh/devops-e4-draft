# E8 B3 决策记录

背景：接续 B1 的固定样例，需向 B2 提供可追溯、与项目版本一致的 MD 报告。

选择：复制 B1 样例及内部 Git 历史到 B3 独立 OUT，复用已验证的镜像 ID。对副本采集实际依赖，比较报告 commit、项目 HEAD、B1 样例提交，并核对精确发现集合、采集前后全部受跟踪文件的 SHA-256 和干净工作区。

替代方案：直接在 B1 原始目录写产物可能混淆责任与证据；重新创建 fixture 会生成另一份内部 Git 历史，无法继续使用 B1 指定的样例提交。故本次采用保留提交的副本。

代价：增加一份小型样例与 Git 历史副本；只比较 HEAD 不能识别所有未提交输入变化，因此同时检查工作区和文件哈希。固定报告是一次采集结果，项目随后变化时应重新采集，不能人工改写报告 commit。

验证：`report-identity.json` 六项检查通过；输入文件前后哈希一致；9 项测试通过。交接样例未生成或应用 Patch，B2、B4 的验证另行记录。共享变量修复策略属于后续实现阶段，本次未作实现决策。
