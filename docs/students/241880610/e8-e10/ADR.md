# ADR：个人 E8-E10 B 组实验取舍

## 决策

使用课程 `labs/e8e10/lab.py` 的固定样例分别运行 E8、E9、E10，每个阶段使用独立的 `work/` 目录。候选生成与候选接受分离，失败场景只在临时副本中验证。

## 原因

- 独立 OUT 能把每阶段输入、命令和结果分开保存。
- E9 的 direct、macro、mixed 需要分别保留 Patch 和 plan。
- E10 只有全部质量检查通过才写回源项目，拒绝场景必须保留源文件不变证据。

## 代价

个人运行记录体积较大，`work/` 证据不直接提交到 Git，而在报告中记录路径和关键结果；后续需要按组内要求归档完整 OUT。
