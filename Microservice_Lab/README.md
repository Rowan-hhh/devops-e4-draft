# 微服务实验

在本组云服务器运行一个 API 和一个下游 Worker，记录任务从正常、失败到恢复的过程。用 Prometheus 和 Grafana 观察指标，按 `job_id` 查日志。最后用本组仓库和真实提交完成 E12 集成验证。

|文件|用途|
|---|---|
|[docs/01_样例操作.md](docs/01_样例操作.md)|部署、采集、停机和恢复，按顺序执行|
|[docs/02_本组项目接入.md](docs/02_本组项目接入.md)|接入本组服务，提交真实 Git 项目，核对构建、检测、补丁与复验|
|[docs/03_验收与排错.md](docs/03_验收与排错.md)|检查结果，整理提交文件|
|`compose.yaml`、`app/`|样例的部署配置、服务代码和两份依赖集合|
|`monitoring/`|Prometheus 抓取配置、Grafana 数据源和面板|
|`scripts/lab.py`、`scripts/project.py`|提交任务，保存并核对结果|
|[templates/实验记录.md](templates/实验记录.md)|填写本组的实验记录|

将 ZIP 上传到服务器，解压后从 **01_样例操作** 开始。样例使用固定的依赖集合，验证服务调用、日志、指标和恢复。四项论文能力使用本组 E12 项目验证。
